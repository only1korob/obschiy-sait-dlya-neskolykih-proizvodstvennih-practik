# 🏛️ Проект: Информационная система «Пекарня и кондитерская»

Индивидуальный проект по разработке и оптимизации веб-приложения в рамках модуля ПМ.03. Приложение представляет собой систему управления пекарней с готическим интерфейсом и интеграцией с базой данных MySQL.

## 📝 Описание предметной области
Система предназначена для автоматизации работы кондитерской. Основной акцент сделан на:
* Учет заказов и продаж.
* Управление системными интеграциями.
* Автоматизацию резервного копирования данных.
* Безопасную регистрацию и авторизацию пользователей.

## 🛠️ Технологический стек
* Backend: Python 3.x, Flask
* Database: MySQL / MariaDB
* Frontend: HTML5, CSS3 (Custom Gothic Style), Jinja2 templates
* Библиотеки: mysql-connector-python, flask
